## 1단계 구현 기능
1. 제목 컴포넌트 구현
    - 제목 텍스트의 라인을 최대 1줄로 제한한다.
    - 오버플로우 발생 시 ...으로 표시한다.
    - Input이 빈 값일 때 기본 값으로 “LazyColumn 컴포넌트 구현”을 화면에 띄운다.
2. 내용 컴포넌트 구현
    - 내용 텍스트의 라인을 최대 2줄로 제한한다.
    - 오버플로우 발생 시 ...으로 표시한다.
    - null 체크를 통해 Input이 빈 값이 아닐때만 화면에 띄운다.
3. 태그 컴포넌트 구현
    - 태그 글자 수가 5글자를 넘어간다면, 5글자만 화면에 띄운다.
    - 태그 모서리 쉐입을 라운드로 설정한다.
4. 태그 FlowRow 컴포넌트 구현
    - 태그 개수가 5개를 넘어간다면, 5개만 화면에 띄운다.
5. 프로필 정보 컴포넌트 구현
    - 프로필 Icon
    - 프로필 이름
        - 프로필 이름의 라인 최대 1줄로 제한한다.
        - 오버플로우 발생 시 ...으로 표시한다.
6. 카드 컴포넌트 구현
    - 카드 너비 286px으로 고정한다.
    - 내용 컴포넌트와 프로필 정보 컴포넌트 사이에 구분선을 추가한다.
7. 칸반보드 컴포넌트 구현
    - 칸반 카드 모서리 쉐입을 라운드로 설정하고, 테두리를 추가한다.
    - 내부 컴포넌트 배치 간격을 12px로 설정한다.

## 2단계 구현 기능
[단위 테스트]
- 태그가 비어있거나 공백만 있다면 태그를 생성할 수 없다.
- 프로필 이름이 비어있거나 공백만 있다면 프로필을 생성할 수 없다.
- 본문이 비어있거나 공백만 있다면 본문을 생성할 수 없다.
- 제목이 비어있거나 공백만 있다면 제목을 생성할 수 없다.

[UI 테스트]
- 태그가 5글자가 넘었을 때 5글자만 표현된다.
- 태그 그룹의 태그가 5개가 넘었을 때 5개만 표현된다.
- 제목이 화면에 정상적으로 노출된다.
- 본문이 화면에 정상적으로 노출된다.
- 프로필 화면에 정상적으로 노출된다.
- 제목이 길다면 한 줄로, 오버플로우 UI와 함께 표시된다.
- 본문이 길다면 두 줄로, 오버플로우 UI와 함께 표시된다.
- 프로필 이름이 길다면 한 줄로, 오버플로우 UI와 함께 표시된다.
- 칸반 보드 카드가 화면에 정상적으로 노출된다.
  - 제목, 설명, 담당자, 태그가 모두 입력된 카드를 랜더링한다.
      - 제목, 설명, 담당자, 태그가 모두 화면에 정상적으로 노출된다.
  - 제목, 설명, 담당자만 입력된 카드를 랜더링한다.
      - 제목, 설명, 담당자만 화면에 정상적으로 노출된다.
  - 제목, 담당자만 입력된 카드를 랜더링한다.
      - 제목, 담당자만 화면에 정상적으로 노출된다.
